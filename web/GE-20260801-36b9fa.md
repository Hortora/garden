## Symptom

When evaluating Cytoscape.js for a diagram editor requiring custom node shapes (stencil sets with distinct visual identities), there is no documented way to register custom canvas-drawn node types.

## Context

Cytoscape.js is a mature, well-maintained graph visualization library (MIT licensed, framework-agnostic, supports compound nodes and ELK layout). It appears to be a strong candidate for interactive graph editors. However, its node rendering system is closed — nodes are rendered as built-in geometric shapes (rectangle, ellipse, diamond, etc.) styled via CSS-like properties.

## What was tried

- `background-image` with SVG data URIs — works but renders as rasterized bitmap, not interactive SVG
- `cytoscape-layers` plugin `renderPerNode` callback — gives a Canvas 2D context per node, but draws on an overlay layer decoupled from the actual node (interaction and visuals are separated)
- `cytoscape-canvas` extension — similar overlay approach
- Hacking `$$('renderer', 'canvas').nodeShapes` + `$$.style.types.nodeShape.enums` — works but uses undocumented internals that can break on upgrades

## Root cause

Cytoscape.js was designed as a graph *visualization* library, not a graph *editor* toolkit. The canvas renderer is a closed system with a styling API (CSS-like properties on shapes), not a drawing API (Canvas 2D context for custom rendering). GitHub issue #441 has been open since 2014 requesting a public custom shape API.

## Fix

For diagram editors requiring custom-drawn nodes: use a different library. Cytoscape.js is excellent for graph visualization but not suitable as a diagram editor foundation when custom node shapes are needed.

Alternatives for framework-agnostic graph editors with custom node rendering:
- React Flow / xyflow (custom nodes as React/Svelte components)
- ELK.js + custom SVG/Canvas rendering (roll your own)

### Alternatives considered

- **Cytoscape.js overlay workaround**: Using `cytoscape-layers` `renderPerNode` with an invisible base node. Rejected because interaction (selection, drag) remains coupled to the invisible base node while visuals are on the overlay — fragile coupling that breaks with zoom/pan edge cases.
- **Hacking internals**: Modifying `nodeShapes` directly. Rejected because it relies on undocumented APIs that could break on any minor version update.

## Why this is non-obvious

Cytoscape.js has compound nodes (containment), ELK layout support, and a rich event system — all the features a diagram editor needs except custom node rendering. The limitation only becomes apparent after significant evaluation. The `background-image` property suggests SVG support, but it rasterizes to bitmap.
