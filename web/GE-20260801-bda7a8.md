## Symptom

When evaluating React Flow for a non-React project, @xyflow/system appears to be a framework-agnostic core that could be used with Lit/Svelte/vanilla JS. The package is published on npm and the monorepo structure suggests it's the shared foundation.

## Context

The xyflow monorepo has three packages: @xyflow/system, @xyflow/react, @xyflow/svelte. A Svelte binding exists, suggesting the system package provides enough infrastructure for any framework binding.

## Root cause

@xyflow/system is only **25% of the total logic** (~6,500 LOC out of ~26,000 total). It provides:
- Edge path calculation (bezier, smoothstep, straight)
- Coordinate transforms and bounds computation
- XYDrag, XYPanZoom, XYHandle interaction controllers (accept raw DOM elements)
- Graph utility functions

What it does NOT provide (the other 75%):
- Any rendering or DOM management
- Component model (node wrappers, edge wrappers, containers)
- Reactive store (React uses Zustand, Svelte uses runes)
- Selection management, keyboard handling, visible-element culling
- Lifecycle synchronization with a framework

Building a Lit binding on @xyflow/system = writing ~6,000-8,000 LOC (comparable to the Svelte binding at ~7,700 LOC). This is months of work, not a thin wrapper.

## Fix

**Don't build on @xyflow/system unless you're prepared for ~6-8 person-weeks of framework binding work.** The Svelte Flow effort was done by the xyflow team who wrote the internals.

For non-React projects needing React Flow capabilities:
1. **React-in-WebComponent bridge** (~50 lines) — skip Shadow DOM, mount via ReactDOM.createRoot, accept the ~45KB React bundle cost
2. **Wait for an official binding** — the xyflow team may ship one
3. **Build the full binding** — viable but budget 6-8 person-weeks

## Why this is non-obvious

The package name "@xyflow/system" and its position in the monorepo suggest it's the "core" that framework bindings wrap thinly. The actual ratio (25% core / 75% bindings) is not documented anywhere. The Svelte binding being 34% smaller than React suggests less boilerplate, but it's still 7,700 LOC.
