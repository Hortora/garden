## Document-level mousedown bypasses nested shadow DOM focus barrier for xterm.js

**ID:** GE-20260804-4d9ce7
**Stack:** xterm.js, Lit 3.x, nested shadow DOM
**What it achieves:** Reliable click-to-focus for xterm.js terminals hosted inside multiple layers of Lit shadow DOM (e.g. workbench → detail panel → terminal component → xterm textarea).

### Context

xterm.js internally handles mousedown on its screen element to focus its hidden textarea. When the terminal is inside nested shadow roots (3+ levels deep), real browser clicks don't reliably trigger xterm's internal focus handler. Synthetic events dispatched via `evaluate()` work, but physical user clicks don't — the focus chain breaks at a shadow boundary.

### The technique

Add a `mousedown` listener at the `document` level that checks if the click coordinates fall within the terminal area's bounding rect, then forces focus:

```typescript
document.addEventListener('mousedown', (e: Event) => {
  const termArea = this.renderRoot.querySelector('.terminal-area');
  if (!termArea) return;
  const rect = termArea.getBoundingClientRect();
  const me = e as MouseEvent;
  if (me.clientX >= rect.left && me.clientX <= rect.right &&
      me.clientY >= rect.top && me.clientY <= rect.bottom) {
    setTimeout(() => { if (el._terminal) el._terminal.focus(); }, 0);
  }
});
```

The `setTimeout(0)` defers the focus call to after the browser's native click processing completes.

Also add `delegatesFocus: true` to each Lit shadow root in the chain:

```typescript
static override shadowRootOptions = { ...LitElement.shadowRootOptions, delegatesFocus: true };
```

And auto-focus when the terminal connects:

```typescript
if (topic === 'terminal-connected') {
  el._terminal.focus();
}
```

### Why this is non-obvious

Click-to-focus handlers on shadow DOM elements (`@click`, `addEventListener` on the shadow root element) appear to work in synthetic tests but fail with real user clicks. `document.elementFromPoint()` returns the outermost shadow host, suggesting clicks can't reach deep elements — but they actually can (browser native hits DO traverse open shadow roots). The disconnect between synthetic and real click behaviour wastes debugging time. The coordinate-based document-level approach bypasses all shadow DOM complications.
