### Symptom
A CSS grid page with `height: 100%` and `grid-auto-rows: minmax(min-content, 1fr)` inflates all rows equally to fill the viewport. A 25px title row becomes 300px+, creating massive gaps between headers and content.

### Context
Common in dashboard/SPA layouts where a page container is set to `height: 100%` and child components (title, chart, table) are stacked vertically via CSS grid auto-rows.

### Root cause
`1fr` in `minmax(min-content, 1fr)` distributes remaining space in a fixed-height container across all tracks equally. Even `auto` tracks grow to fill remaining space in a fixed-height grid. The combination of `height: 100%` on the container + `1fr` or `auto` tracks = stretched rows.

### Fix
Use `grid-auto-rows: min-content` with `align-content: start` to pack rows at the top:

```css
grid-auto-rows: min-content;
align-content: start;
```

This makes rows strictly content-sized and prevents them from stretching to fill the container height.

### Why this is non-obvious
The intuition is that `auto` means "size to content" — and it does in unconstrained containers. But in a fixed-height container, `auto` tracks CAN grow to fill remaining space. Only `min-content` or `max-content` are strictly content-sized regardless of container height.
