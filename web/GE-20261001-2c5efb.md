### Symptom
When a web component that listens for document-level events (via `onPagesEvent(document, topic, handler)`) is embedded inside another component, any matching event from elsewhere in the DOM overrides the embedded component's property-set state.

### Context
A session-detail component listens for `session:selected` events at the document level to set its `sessionId`. When composed inside an agent-detail component (which sets `sessionId` directly as a property), any other session-list on the page emitting `session:selected` overrides the property-set value — the embedded component responds to events intended for a different instance.

### Root cause
Document-level event listeners don't discriminate between "I'm the target of this event" and "some other instance is the target." The listener fires for ALL matching events on the document, regardless of which component instance should handle them.

### Fix
Add a `composed` boolean property to the component. When `true`, skip document-level listener registration and rely solely on property-set values:

```typescript
@property({ type: Boolean, reflect: true }) composed = false;

override connectedCallback(): void {
  super.connectedCallback();
  if (!this.composed) {
    this._unsubs.push(
      onPagesEvent<{ id: string }>(document, SessionEventTopics.SELECTED, (p) => {
        this.sessionId = p.id;
      }),
      onPagesEvent(document, SessionEventTopics.DESELECTED, () => {
        this.sessionId = undefined;
      }),
    );
  }
}
```

The embedding parent sets the attribute:
```html
<blocks-session-detail composed .sessionId=${sid}></blocks-session-detail>
```

### Why this is non-obvious
Document-level listeners are the standard pattern for cross-component communication in web component architectures. The conflict only surfaces when a component designed for standalone use is composed inside another — a usage the original author may not have anticipated. The fix is simple but the problem is invisible until you embed the component and notice state being overridden by unrelated events.
