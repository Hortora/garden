### Context
Once `page.setViewportSize()` is called, Playwright caches the device metrics override internally. Every subsequent `clearDeviceMetricsOverride` CDP call, page reload, or navigation triggers Playwright to re-apply the cached override — making it impossible to restore native DPR on that page.

### Technique
Create a new page in the same browser context. New pages don't inherit the per-page device metrics cache:

```javascript
async (page) => {
  const context = page.context();
  const newPage = await context.newPage();
  await newPage.goto('http://localhost:8090');
  await page.close();
  // newPage.evaluate(() => window.devicePixelRatio) → 2 (native Retina)
  return newPage;
}
```

### Why non-obvious
The natural approach is `Emulation.clearDeviceMetricsOverride` via CDP — it's the documented undo for `setDeviceMetricsOverride`. It executes successfully but has no effect because Playwright's internal state management re-applies the override. The fix requires understanding that Playwright's override is per-page, not per-context.
