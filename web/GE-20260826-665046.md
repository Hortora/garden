## Symptom

SVG export of a simple 6-node diagram produces a 1.2MB file. The SVG is valid but massive.

## Context

`html-to-image`'s `toSvg()` serialises a DOM subtree into an SVG with `<foreignObject>`. It clones every element and copies the full `getComputedStyle()` output onto each element's inline `style` attribute — every CSS property, including defaults like `accent-color: auto`, `place-content: normal`, `alignment-baseline: auto`.

With ~400 CSS properties per element and ~80 elements in a React Flow diagram, inline styles account for 99% of the file size (1244KB of 1255KB in the measured case).

## Fix

Post-process the SVG data URL to strip all but visually essential CSS properties:

```typescript
const KEPT_STYLE_PROPS = new Set([
  'color', 'opacity', 'visibility',
  'background', 'background-color', 'background-image',
  'border', 'border-radius', 'box-shadow',
  'font', 'font-family', 'font-size', 'font-weight',
  'line-height', 'text-align', 'text-decoration', 'white-space',
  'display', 'position', 'top', 'right', 'bottom', 'left',
  'width', 'height', 'min-width', 'min-height', 'max-width', 'max-height',
  'margin', 'padding', 'flex', 'flex-direction', 'gap',
  'transform', 'transform-origin', 'z-index', 'box-sizing', 'overflow',
  'fill', 'stroke', 'stroke-width', 'stroke-dasharray',
  // ~60 properties total
]);

function stripBloatedStyles(svgDataUrl: string): string {
  return svgDataUrl.replace(/style="([^"]*)"/g, (_match, styleStr) => {
    const kept = [];
    for (const decl of styleStr.split(';')) {
      const colon = decl.indexOf(':');
      if (colon < 0) continue;
      const prop = decl.substring(0, colon).trim();
      if (KEPT_STYLE_PROPS.has(prop)) kept.push(decl.trim());
    }
    return kept.length > 0 ? `style="${kept.join('; ')}"` : '';
  });
}
```

Apply after `toSvg()` returns, before creating the download blob. Also add `skipFonts: true` to the `toSvg` options to prevent font embedding.

Result: 1255KB → 83KB (93% reduction) with identical visual output.

## Why this is non-obvious

The file size looks like it could be caused by embedded fonts, images, or complex SVG paths. The actual cause — every element carrying a 16KB inline style attribute full of default CSS values — is only visible by inspecting the SVG source and measuring style attribute sizes.
