## Symptom

Need to use a React-based library (e.g. React Flow for graph editing) inside a Lit 3.x Web Component application, without introducing React as an app-wide framework.

## Context

The host application is entirely Lit Web Components. A specific component needs React Flow's graph editing capabilities. React Flow relies on document-level event handlers, portal-based controls, and CSS-in-JS injection — all incompatible with Shadow DOM.

## Fix

### The bridge component (~50 lines)

```typescript
import { LitElement, html } from 'lit';
import { customElement, property } from 'lit/decorators.js';
import * as React from 'react';
import * as ReactDOM from 'react-dom/client';

@customElement('react-bridge')
class ReactBridge extends LitElement {
  private root?: ReactDOM.Root;

  // Skip Shadow DOM — React needs light DOM
  override createRenderRoot() { return this; }

  override connectedCallback() {
    super.connectedCallback();
    const container = document.createElement('div');
    this.appendChild(container);
    this.root = ReactDOM.createRoot(container);
    this.renderReact();
  }

  override disconnectedCallback() {
    this.root?.unmount();
    super.disconnectedCallback();
  }

  override updated() {
    this.renderReact();
  }

  private renderReact() {
    this.root?.render(React.createElement(MyReactComponent, { ...this.reactProps }));
  }
}
```

### CSS isolation (required when Shadow DOM is disabled)

```css
.react-bridge-root {
  all: initial;  /* Reset inherited host styles */
  /* Re-declare design tokens — all:initial kills custom properties */
  --token-primary: var(--host-primary, #0066cc);
  --token-spacing: var(--host-spacing, 8px);
}

@layer bridge.library {
  /* Library CSS scoped to this layer — prevents host globals from leaking in */
}

@layer bridge.custom {
  /* Custom styles for React components */
}
```

### Key points

1. **Skip Shadow DOM** on the bridge component only — sibling Lit components keep their shadow roots
2. **`all: initial`** resets inherited styles but also kills CSS custom properties — must explicitly re-declare design tokens on the container
3. **CSS `@layer`** prevents host globals (`* { box-sizing }`, resets) from affecting React internals
4. **Lifecycle**: mount in `connectedCallback`, unmount in `disconnectedCallback`, re-render in `updated()`
5. **Props**: pass Lit `@property` values as React props; React callbacks emit Lit CustomEvents with `composed: true`
6. **Bundle cost**: ~45KB gzipped for React + ReactDOM — acceptable for a single specialized component

## Why this is non-obvious

The most-cited concern (Shadow DOM event retargeting breaking React) disappears entirely when you skip Shadow DOM on the bridge component. Most guides focus on solving the Shadow DOM problem; the simpler answer is avoiding it. CSS isolation via `@layer` is less well-known than Shadow DOM but more practical for this use case.
