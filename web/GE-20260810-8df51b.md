### Symptom
A LitElement component has `style.height = "450px"` and `style.minHeight = "450px"` set, but `offsetHeight` returns 0. The component is invisible.

### Context
Custom elements default to `display: inline` per the HTML spec. Inline elements ignore `width`, `height`, `min-height`, and `min-width` CSS properties. The element exists in the DOM, has shadow DOM content, and has props/data — but renders as 0-height.

### Root cause
Setting `this.style.height` on an inline element has no effect. The browser accepts the property but doesn't apply it to layout. `offsetHeight` returns 0 because inline elements have no block formatting context.

### Fix
Add `:host { display: block; }` in the component's static styles:

```typescript
static override styles = css`
  ${ParentElement.styles}
  :host { display: block; }
`;
```

### Why this is non-obvious
Other LitElement components in the same codebase may appear to work without `:host { display: block }` — because their shadow DOM children (e.g. a div with `min-height: 300px`) give the inline element intrinsic size. But if a child uses `height: 100%`, it resolves to 0 because the inline parent has no computed height.
