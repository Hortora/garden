## Bridge selection topic pattern for multi-mode dockWorkbench layouts

### Context
A Pages `dockWorkbench` application has multiple left dock navigation panels (e.g. Investigations, Worker Tasks, Work Queue), each with its own `selection-topic`. Right dock contextual panels (audit trail, compliance, routing) need to update based on the selected entity regardless of which navigation mode is active.

### Symptom
Right dock panels that listen to a single mode's selection topic (e.g. `case`) stop updating when the user switches to a different navigation mode (e.g. `work-item`).

### Root cause
`blocks-split-workbench` and `blocks-list-pane` accept only one `selection-topic` at a time. Right dock panels can't listen to multiple topics simultaneously. Each mode emits selections on its own topic — no single topic carries the derived entity ID across all modes.

### Fix
Create a **bridge topic** (e.g. `investigation-context`) that the centre panel publishes to whenever any mode resolves a caseId:

```typescript
// In the centre panel — after each mode resolves a caseId
private _emitInvestigationContext(caseId: string) {
  document.dispatchEvent(new CustomEvent('pages-selection', {
    detail: { topic: 'investigation-context', caseId },
    bubbles: true, composed: true,
  }));
}

// On case selection (investigations mode)
const caseId = row.text('caseId');
if (caseId) this._emitInvestigationContext(caseId);

// On work-item selection (work queue mode) — extract from callerRef
const caseId = extractCaseId(item.callerRef);
if (caseId) this._emitInvestigationContext(caseId);

// On worker-task selection — extract from task.caseId
const caseId = task.caseId;
if (caseId) this._emitInvestigationContext(caseId);
```

Right dock panels subscribe to the bridge topic only:

```typescript
document.addEventListener('pages-selection', (e: Event) => {
  const detail = (e as CustomEvent).detail;
  if (detail.topic === 'investigation-context') {
    this._caseId = detail.caseId;
  }
});
```

### Why this is non-obvious
The natural approach is to have right dock panels listen to all three mode-specific topics. This creates coupling — every new mode requires updating every right dock panel. The bridge pattern inverts the dependency: each mode is responsible for publishing to the bridge, and contextual panels are decoupled from navigation modes entirely.
