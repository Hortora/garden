## Behavior

When the `dock-toggle` event handler shows a deferred (lazy-loaded) panel, it restores the panel's display property from the `dataset.pagesDisplay` attribute. If `pagesDisplay` is empty or `"block"`, the panel appears but its content does not stretch to fill the allocated flex space.

For dock panels (as opposed to inline content panels), pre-setting `dataset.pagesDisplay = "flex"` in the component's activation callback allows content to expand correctly when the panel is shown.

## Stack

- TypeScript / React
- casehub-pages dock system with deferred panel loading
- `dock-toggle` event handler
- `HTMLElement.dataset.pagesDisplay` attribute

## Where It Happens

Dock panels are often lazy-loaded to reduce initial bundle size. When the user first opens a panel:

1. The panel component is initialized (activation callback runs)
2. The panel is marked deferred and hidden (`display: none`)
3. Later, when the user clicks to show the panel, `dock-toggle` fires
4. `dock-toggle` restores the display property from `dataset.pagesDisplay`
5. If `pagesDisplay` is unset or `"block"`, content stays at intrinsic height

## Documented Discovery Method

Reading the source of the `dock-toggle` event handler reveals the restoration logic:

```typescript
const storedDisplay = el.dataset.pagesDisplay || "";
el.style.display = storedDisplay; // Restores from dataset, defaults to ""
```

This pattern is not documented in any API reference — only discoverable via source inspection.

## Solution

In the component's activation callback, pre-set the display style to "flex" if the component has flex-based content:

```typescript
function activateMyPanel() {
  const panelEl = document.querySelector('[data-panel="my-panel"]');
  
  // Pre-set display style for dock restoration
  panelEl.dataset.pagesDisplay = "flex";
  
  // Also set flex: 1 on rendered children so they stretch
  const contentChildren = panelEl.querySelectorAll('[role="main"]');
  contentChildren.forEach(child => {
    (child as HTMLElement).style.flex = "1";
    (child as HTMLElement).style.minHeight = "0";
  });
}
```

When `dock-toggle` later restores the panel's visibility, it will apply `display: flex`, and the children will stretch to fill the allocated space.

## Why This is Undocumented

The `dataset.pagesDisplay` attribute is a private implementation detail of the `dock-toggle` event handler. There is no mention of it in the public dock API, component lifecycle documentation, or examples. The default behavior (empty string → no explicit display style) works for simple inline panels but fails silently for flex-based layouts.

## Caveats

- Only necessary for panels with flex-based content layout. Simple text/button panels work fine with default `display: block`.
- The attribute name `pagesDisplay` is a project-internal naming convention (pages-specific display override).
- If the panel is shown via a method other than `dock-toggle`, the `dataset.pagesDisplay` setting has no effect.
