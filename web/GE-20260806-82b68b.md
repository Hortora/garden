### Symptom
Need to set z-index, inject custom buttons, or add click handlers on Dockview floating groups — but no documented API for accessing the container DOM elements.

### Context
Using Dockview v7+ in floating-only mode (all groups are floating, no docked panels). Need to manage z-order across frames, inject pin/detach buttons into titlebars, and handle click-to-front behavior.

### Root cause
Dockview's floating group DOM structure is not documented. The library manages its own DOM and the public API (`DockviewComponent`, `DockviewGroupPanel`) doesn't expose container element accessors for floating groups.

### Fix
Access the floating group's DOM through the group object:

```typescript
// Get the outermost container for a floating group
const el = group.element ?? group.header?.element;
const container = el.closest('.dv-resize-container') as HTMLElement;

// Set z-index on this container
container.style.zIndex = String(zIndex);

// Access the titlebar for chrome injection (buttons, etc.)
const titlebar = container.querySelector('.dv-floating-titlebar');
titlebar.prepend(myButton);

// Listen for clicks on the container
container.addEventListener('pointerdown', () => bringToFront(frameId));
```

DOM hierarchy for a floating group:
```
.dv-resize-container          ← outermost, set z-index here
  .dv-floating-titlebar        ← inject custom chrome here
  .dv-grid-view
    .dv-groupview              ← has border-radius, background
      .dv-tabs-and-actions-container
      .dv-content-container    ← panel content renders here
```

### Why this is non-obvious
No official documentation for the internal DOM structure. The only way to discover it is DOM inspection in the browser. The `group.element` accessor is not documented but provides the entry point.
