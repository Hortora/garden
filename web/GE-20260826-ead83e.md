### Symptom

When narrowing `ContainerState | readonly FrameLayout[]` with `Array.isArray()`, the else branch retains the full union type instead of narrowing to just `ContainerState`.

```typescript
let containerState: ContainerState | undefined;
// TS error: Type 'readonly FrameLayout[] | ContainerState' is not assignable to type 'ContainerState | undefined'
containerState = Array.isArray(savedLayout)
  ? migrateFrameLayout(savedLayout)  // correctly narrowed to FrameLayout[]
  : savedLayout;                      // NOT narrowed — still ContainerState | readonly FrameLayout[]
```

### Context

This occurs when using `Array.isArray()` on a union where one member is an array type and the other is an object type with array-valued properties (like `ContainerState` which has a `tabs: readonly FrameTabConfig[]` property). TypeScript's `Array.isArray` type guard narrows the true branch to the array member but does not exclude it from the false branch.

### Root cause

TypeScript's control flow analysis for `Array.isArray()` uses a special narrowing rule that extracts array types in the true branch. However, the false branch keeps the full union rather than subtracting the array type. This is a known limitation — TypeScript cannot prove that a non-array value in the union couldn't also satisfy `Array.isArray()` in some edge cases.

### Fix

Use an explicit type assertion in the else branch:

```typescript
containerState = Array.isArray(savedLayout)
  ? migrateFrameLayout(savedLayout as readonly FrameLayout[])
  : savedLayout as ContainerState;
```

The `as ContainerState` is safe because if `Array.isArray()` returns false, the value must be a `ContainerState` — arrays are the only other member of the union.

### Why this is non-obvious

Most developers expect `Array.isArray()` to work symmetrically as a type guard — narrowing both branches of the conditional. The true branch behaves as expected, so the false branch failure is surprising. The fix (explicit cast) feels wrong because it looks like you're overriding the type checker, when in fact you're compensating for an incomplete narrowing.

### Alternatives considered

- Type predicate function wrapping `Array.isArray` — works but adds indirection for a single-use check
- Checking a discriminant property (`'layout' in savedLayout`) — works but requires knowing which property is unique to the non-array type
