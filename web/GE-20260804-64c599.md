## Symptom

`addEventListener('topic-name', handler)` never fires for SSE events

## Context

When an SSE endpoint sends events without an `event:` field in the stream, they arrive as generic `message` events. Using `addEventListener('custom-name')` never receives them.

## Root Cause

SSE spec requires `event: name` field in the stream for named events. Without it, all events are type `message`. The topic is in the JSON payload, not the SSE event type.

## Fix

Use `eventSource.onmessage = handler` instead of `eventSource.addEventListener('topic-name', handler)`. Parse the topic from the JSON payload if needed.

## Why Non-Obvious

The SSE endpoint accepts `?topics=agent:state` as a parameter, suggesting the events would arrive with that type. The EventSource connects successfully and readyState=OPEN, giving no indication that the listener is wrong.
