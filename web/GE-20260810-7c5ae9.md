### Symptom
Content beneath a Dockview floating overlay is completely hidden — the centre
content area appears as a solid dark background with only floating panels visible.

### Context
When using `DockviewComponent` inside a `pointer-events:none` overlay container
to render floating panels above a main content area, the Dockview grid itself
obscures the content underneath.

### Root cause
The `.dv-grid-view.dv-dockview` element receives `background: rgb(30, 30, 30)`
from the dockview theme (e.g. `themeDark`). Even though the shell element
(`.dv-shell`) is transparent, the internal grid view has its own opaque
background that covers the full overlay area.

### Fix
After constructing `DockviewComponent`, override the grid background:

```typescript
dockview = new DockviewComponent(el, { ... });
const grid = el.querySelector<HTMLElement>(".dv-grid-view.dv-dockview");
if (grid) grid.style.background = "transparent";
```

The floating panels retain their own backgrounds from the theme — only the
grid container (which holds the non-floating layout) needs to be transparent.

### Why this is non-obvious
The `.dv-shell` wrapper is transparent, suggesting the theme handles
transparency correctly. The opaque background is on an inner element
(`.dv-grid-view`) that's not obviously responsible for the full-area fill.
Inspecting the shell alone gives a false all-clear.
