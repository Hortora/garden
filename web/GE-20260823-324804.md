### Symptom

`blocks-audit-trail-viewer` ignores the `endpoint` property for URL construction — requests always go to `${endpoint}/api/v1/ledger/entries?subjectId=...` regardless of what the app needs.

### Context

Building a compliance audit view in a casehub application (e.g. SOC, AML, Clinical) that needs cross-entity browsing at app-specific REST endpoints (e.g. `/api/soc/compliance/entries`). The component's `endpoint` property looks configurable but the URL suffix is hardcoded.

### Root cause

`_updateEndpoints()` (private method, line 148) constructs URLs as:
```typescript
const entriesUrl = new URL(`${this.endpoint}/api/v1/ledger/entries`, base);
```

Two limitations:
1. The `/api/v1/ledger/entries` suffix is hardcoded — no way to point at app-specific paths
2. `subjectId` is required (line 149 guard) — without it, endpoints are set to `undefined` and no fetch occurs. No cross-entity browsing possible.

No extension point exists — `_updateEndpoints()` is private, can't be overridden.

### Fix

Build a custom component using the same primitives (`pages-table`, `renderPropertyTree`, `propertyTreeStyles` from `@casehubio/pages-ui-components`). The SOC implementation (`soc-audit-trail.ts`, ~300 lines) replicates the visual design with app-specific endpoints, server-side pagination, and cross-incident browsing.

File a platform issue for `blocks-audit-trail-viewer` to support:
- Configurable URL patterns (or a `sourceFactory` extension point)
- Optional `subjectId` for cross-entity browsing

### Why this is non-obvious

The `endpoint` property suggests the component is configurable for any REST backend. A developer would naturally set `endpoint="/api/soc/compliance"` and expect the component to fetch from that prefix. The hardcoded suffix is invisible without reading the source — it's not documented as a limitation.

### Alternatives considered

- **Proxy endpoints** matching the platform URL pattern — creates confusing REST routing and couples the app to the platform's internal API shape
- **Forking the component** — maintenance burden and diverges from upstream improvements
