### Symptom
Calling `ide_insert_member` on a TypeScript file returns: "Member editing not supported for TypeScript. Supported: Java, Kotlin."

### Context
`ide_insert_member` is documented for structural editing — inserting methods, fields, constructors at named positions. The error only appears after the call, not from tool schema inspection.

### Root cause
The IntelliJ MCP plugin's structural editing tools (`ide_insert_member`, `ide_edit_member`, `ide_replace_member`) are implemented only for Java and Kotlin PSI trees. TypeScript PSI support is not included.

### Fix
For TypeScript files, use `Edit` with `replace_all: true` to append or modify code blocks. For new files, use `ide_create_file` or `Write`. `ide_replace_text_in_file` works for single-line substitutions in TS files.

### Why this is non-obvious
The tool accepts a `file` parameter with no language restriction in its schema. The limitation is only discovered at call time, after planning an approach around structural editing.
