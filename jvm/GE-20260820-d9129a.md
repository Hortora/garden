### Context

Building a familiarity score for per-user relationship modeling. The score should increase gradually: a single positive interaction should produce a low score, while many positive interactions should produce a high score. The score maps to relationship stages via configurable thresholds (stranger < 0.2, acquaintance < 0.4, friend < 0.6, etc.).

### The obvious approach (didn't work well)

Laplace-smoothed sentiment ratio:

```java
double rawScore = (positive * positiveWeight - negative * negativeWeight)
                  / (positive + negative + neutral + 1.0);  // +1 = Laplace smoothing
double normalised = (rawScore + 1.0) / 2.0;  // map [-1,1] to [0,1]
```

With 1 positive signal: `rawScore = 1.0 / 2.0 = 0.5`, normalised to `0.75` — which exceeds the "friend" threshold (0.6). A single "hello" makes someone a friend. The Laplace smoothing dampens the denominator but not enough to prevent high scores from low interaction counts.

### Fix — volume factor

Multiply the sentiment score by a volume factor that starts near zero and asymptotically approaches 1.0 as interaction count grows:

```java
int total = positive + negative + neutral;
if (total == 0) return 0.0;
double sentiment = (positive * positiveWeight - negative * negativeWeight) / total;
double sentimentNorm = Math.max(0.0, Math.min(1.0, (sentiment + 1.0) / 2.0));
double volumeFactor = 1.0 - 1.0 / (1.0 + total * 0.1);  // 0→0, 10→0.5, 50→0.83
double score = sentimentNorm * volumeFactor;
```

The `0.1` coefficient controls how quickly volume builds. At 1 interaction the volume factor is ~0.09 (score stays very low). At 10 interactions it's ~0.5 (mid-range possible). At 50 it's ~0.83 (high scores achievable). This produces the gradual progression that relationship staging requires.

### Why this is non-obvious

Laplace smoothing is the standard fix for small-sample instability in ratio-based scores. A developer reaching for `(count + 1)` in the denominator would expect it to handle single-interaction edge cases — and it does prevent division by zero, but it doesn't prevent the ratio itself from being high. The insight is that ratio stability and volume confidence are separate concerns: Laplace handles the first but not the second. The volume factor (`1 - 1/(1 + n*k)`) is a sigmoid-like growth curve that directly encodes "more interactions = more confidence in the score."
