### What it does

`AgentDescriptorRegistrar` (in `io.casehub.eidos.api.spi`) is a `@FunctionalInterface` with a single method:

```java
List<AgentDescriptor> descriptors();
```

CDI-discovered `@ApplicationScoped` beans implementing this interface are called at startup. The returned descriptors are registered in the `AgentRegistry` by the eidos runtime.

### Why this is non-obvious

The name `Registrar` suggests a callback pattern — `register(AgentRegistry registry)` — where the implementation pushes descriptors into a registry. Instead, it's a producer pattern: the implementation returns descriptors, and the framework handles registration. This is discoverable only by reading the source.

### Context

Any CaseHub application repo that needs to register domain-specific agents (e.g., fsitrading registering 7 strategy agent descriptors) must implement this SPI. Getting the pattern wrong (expecting a registry parameter) wastes time until the source is checked.
