### Symptom

Need to consume AgentProvider responses but the sealed interface hierarchy is not documented in any README or Javadoc. Unknown what event types to expect and how to extract plain text from the stream.

### Context

AgentProvider.invoke(AgentSessionConfig) returns Multi<AgentEvent>. AgentEvent is a sealed interface with no obvious documentation about its variants or how to consume them for simple text extraction.

### Root cause

The API is internal/pre-release — no published documentation exists for the AgentEvent type hierarchy. Discovery requires decompiling the jar or reading the class files.

### Fix

AgentEvent is sealed with these variants:

```java
public sealed interface AgentEvent {
    record TextDelta(String text) implements AgentEvent {}
    record ThinkingDelta(String text) implements AgentEvent {}
    record ToolCallDelta(int index, String id, String name, String partialArguments) implements AgentEvent {}
    record ToolCallComplete(int index, String id, String name, String arguments) implements AgentEvent {}
    record ToolResult(String toolCallId, String content, boolean isError) implements AgentEvent {}
    record InvocationComplete(int inputTokens, int outputTokens, int thinkingTokens,
        int cacheReadTokens, int cacheWriteTokens, Double totalCostUsd,
        long durationMs, long apiDurationMs, String sessionId, int numTurns, boolean isError)
        implements AgentEvent {}
}
```

For blocking text extraction from the stream:

```java
var events = agentProvider.invoke(sessionConfig)
    .collect().asList()
    .await().atMost(Duration.ofMinutes(2));

String text = events.stream()
    .filter(AgentEvent.TextDelta.class::isInstance)
    .map(AgentEvent.TextDelta.class::cast)
    .map(AgentEvent.TextDelta::text)
    .collect(Collectors.joining());
```

AgentSessionConfig factory: `AgentSessionConfig.of(systemPrompt, userPrompt)` creates a minimal config with no MCP servers, no timeout, no correlation ID.

### Why this is non-obvious

The only way to discover the AgentEvent hierarchy is to decompile the jar. There is no Javadoc, no README, and no usage examples in the casehub-platform-agent-api artifact. The blocking pattern using Mutiny's `.collect().asList().await()` is the correct approach for synchronous callers but is not documented alongside the streaming API.
