## Instant.EPOCH as initial watermark triggers quiet period bypass on first compositor synthesis

### Symptom

Tests asserting `Skipped("insufficient reflections")` or `Skipped("low novelty")` receive `Synthesised` instead. Count and novelty gates appear to be completely ignored on first synthesis when no prior state exists.

### Context

Compositor-pattern components (e.g. `NarrativeSynthesiser`) use a composite gate with three mechanisms: count gate, novelty gate, and quiet period bypass. The quiet period bypass is designed to force re-synthesis after extended inactivity — if `Duration.between(lastSynthesis, now) >= quietPeriodBypass`, count and novelty gates are skipped.

When no prior state exists (`NarrativeStore.load()` returns null), the watermark defaults to `Instant.EPOCH`. This is standard practice — EPOCH means "since the beginning of time."

### Root cause

`Duration.between(Instant.EPOCH, Instant.now())` produces a duration of ~56 years — astronomically larger than any configured `quietPeriodBypass` (default: 120 minutes). The `>=` comparison always evaluates to true, so the quiet period bypass always triggers on first synthesis.

This means on first synthesis, the count and novelty gates are always bypassed. Any test that:
1. Sets `narrativeStore.load()` to return null (simulating first synthesis)
2. Expects the count gate to reject insufficient reflections

...will fail because the quiet period bypass short-circuits the gates.

The `>=` boundary also means the comparison is inclusive — a state with `synthesisedAt` exactly `quietPeriodBypass` duration ago triggers bypass. A test using `EARLIER = now - 2 hours` with a 120-minute quiet period will unexpectedly trigger bypass.

### Fix

Tests that need gate enforcement (count or novelty) must provide a recent existing state, not null:

```java
// Wrong — EPOCH triggers quiet period bypass, gates are skipped
when(narrativeStore.load("agent-1", "tenant-1")).thenReturn(null);

// Wrong — exactly 2 hours = quiet period default, >= triggers bypass
var twoHoursAgo = FIXED_NOW.minus(Duration.ofMinutes(120));
when(narrativeStore.load("agent-1", "tenant-1"))
        .thenReturn(existingState(twoHoursAgo, List.of()));

// Right — 30 minutes ago, well within quiet period
var recentSynthesis = FIXED_NOW.minus(Duration.ofMinutes(30));
when(narrativeStore.load("agent-1", "tenant-1"))
        .thenReturn(existingState(recentSynthesis, List.of()));
```

The first-synthesis behaviour (EPOCH → bypass) is by design — a new agent should synthesise immediately when reflections exist. But test authors must understand that null state = no gates.

### Why this is non-obvious

The quiet period bypass is designed for the idle-agent case ("hasn't synthesised in 2 hours, force a refresh"). Using `Instant.EPOCH` as the initial watermark is a standard convention for "since the beginning." The connection between these two — that EPOCH makes the bypass permanent for first synthesis — requires mentally computing a Duration across 56 years and comparing it to 120 minutes. Most developers don't trace through the gate evaluation when writing tests for a specific gate; they focus on the gate they're testing and miss the bypass that fires first.

### Alternatives considered

- Making quiet period bypass only trigger when `currentState != null` — would fix the test issue but changes semantics: first-ever synthesis would need 5 reflections to accumulate before any narrative forms, which is a poor agent experience.
- Using `Instant.MAX` as the initial watermark — produces arithmetic overflow in `Duration.between()`.
