### Symptom

Need Bayesian Beta trust scoring with temporal decay but don't need the full ledger persistence pipeline (JPA, Flyway migrations, Merkle chain).

### Context

The ledger's trust infrastructure (`TrustScoreComputer`, `TrustScoreCalculator`, `DecayFunction`) is designed for enterprise audit trails with JPA-backed persistence. For game sessions, demo apps, or lightweight cognitive agents, the database overhead is unnecessary.

### Fix

Use the in-memory ledger stores with the domain-agnostic `PlainLedgerEntry`:

1. Add `casehub-ledger-memory` dependency (provides `InMemoryLedgerEntryRepository`)
2. Create entries using `PlainLedgerEntry` (concrete `LedgerEntry` subclass with no domain-specific fields)
3. Create `LedgerAttestation` objects and save via `LedgerEntryRepository.saveAttestation()`
4. Query back and feed to `TrustScoreComputer`:

```java
var computer = new TrustScoreComputer(halfLifeDays);
var entries = ledgerRepo.findByActorId(actorId, Instant.EPOCH, Instant.now(), tenantId);
var attestationMap = entries.stream()
    .collect(Collectors.toMap(e -> e.id,
        e -> ledgerRepo.findAttestationsByEntryId(e.id, tenantId)));
var score = computer.compute(entries, attestationMap, Instant.now());
// score.trustScore() in [0.0, 1.0], score.alpha(), score.beta()
```

`InMemoryLedgerEntryRepository` uses `ConcurrentHashMap` — no database, no JPA, no Flyway. Call `clear()` at session boundaries to prevent unbounded growth.

`PlainLedgerEntry` (from ADR-0016) works with both in-memory and JPA stores — switching to durable persistence is a `quarkus.arc.selected-alternatives` config change, not a code change.

### Why this is non-obvious

The ledger documentation focuses on the enterprise audit use case (JPA, Merkle chains, GDPR erasure). `TrustScoreComputer` is pure Java with no CDI, but this isn't highlighted — you'd have to read the constructor javadoc to discover it's usable standalone. The `casehub-ledger-memory` module's javadoc says "suitable for short-lived processes (test suites, single game sessions)" but doesn't show the trust scoring integration pattern.
