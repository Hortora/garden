### Symptom

Need to test a service that injects AgentProvider (LLM invocation interface) without adding Mockito to the project. Must verify: (a) whether the LLM was called at all, (b) what prompt was sent, (c) the service correctly processes the canned response.

### Context

Quarkus CDI projects that use casehub-platform-agent-api for LLM integration but do not include Mockito. The AgentProvider interface has two methods: `invoke(AgentSessionConfig) → Multi<AgentEvent>` and `openSession(AgentSessionInit) → AgentSession`. Services typically only use `invoke()`.

### Fix

Create a static inner class in the test that implements AgentProvider with observable state:

```java
static class TestAgentProvider implements AgentProvider {
    private final String response;
    int invocationCount = 0;
    String lastUserPrompt;

    TestAgentProvider(String response) {
        this.response = response;
    }

    @Override
    public Multi<AgentEvent> invoke(AgentSessionConfig config) {
        invocationCount++;
        lastUserPrompt = config.userPrompt();
        return Multi.createFrom().items(
            new AgentEvent.TextDelta(response),
            new AgentEvent.InvocationComplete(
                100, 50, 0, 0, 0, 0.001, 500L, 400L, "test", 1, false));
    }

    @Override
    public AgentSession openSession(AgentSessionInit init) {
        throw new UnsupportedOperationException();
    }
}
```

Use in tests by injecting into the service via a `forTest(...)` factory:

```java
var agent = new TestAgentProvider("canned response");
var service = CoordinatorService.forTest(config, accumulator, filter,
    assembler, agent, store, ring, cache, recorder, ds);

service.handleMessage(request);
assertEquals(1, agent.invocationCount);
assertTrue(agent.lastUserPrompt.contains("expected content"));
```

### Why this is non-obvious

The natural instinct is to add Mockito for provider testing. This pattern avoids the dependency entirely by exploiting the fact that AgentProvider is an interface with only two methods, and Multi can be constructed from static items. The InvocationComplete event at the end signals stream completion — without it, blocking collectors like `.collect().asList().await()` may hang.
