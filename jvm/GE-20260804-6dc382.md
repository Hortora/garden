## Symptom

Paused terminal disappears from the list intermittently

## Context

`AgentProcessManager.pauseAgent()` kills the process via `treeKill()`, then updates the agents map to PAUSED. A concurrent poll cycle can fire between these two operations.

## Root Cause

The poll sees `foreground=shell + state=RUNNING` (agents map not yet updated) and removes the agent entry. The subsequent `agents.put(PAUSED)` re-adds it, but the poll's broadcast already told the frontend "agent ended."

## Fix

Move `agents.put(terminalName, AgentProcess.paused(command))` BEFORE `treeKill()`. The poll then sees PAUSED and skips.

## Why Non-Obvious

The race window is tiny in development (mock treeKill is instant) but real in production where treeKill takes seconds (SIGTERM → 5s timeout → SIGKILL tree walk).
