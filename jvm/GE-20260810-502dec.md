### Symptom
Compilation error: `cannot find symbol: method setFunction(WorkerFunction)` when trying to modify YAML-loaded Workers in `YamlCaseHub.augment()`.

### Context
`Worker` is a Java record — all fields are final, no setters exist. YAML-loaded workers that don't declare a `do:` block or agent block get `WorkerFunction.NONE` as their function. You can't modify them in-place.

### What was tried
Iterating `definition.getWorkers()`, finding by name, calling `setFunction()` — fails at compile time.

### Root cause
Records are immutable by design. `Worker(name, capabilityNames, function, executionPolicy, description)` — all components are final. The `getWorkers()` list is mutable, but the Worker instances in it are not.

### Fix
Remove YAML workers with no function, then add new Workers with functions:
```java
@Override
protected void augment(CaseDefinition definition) {
    var workers = definition.getWorkers();
    workers.removeIf(w -> w.function() == WorkerFunction.NONE);
    workers.add(Worker.builder()
        .name("my-worker")
        .capabilityName("my-capability")
        .function(input -> WorkerResult.of(Map.of("result", "done")))
        .build());
}
```

### Why this is non-obvious
The YAML defines workers with names and capability mappings. The natural expectation is to find those workers and attach functions to them — the "augment" name suggests modification, not replacement. The removeIf + add pattern is the only way because records are immutable.
