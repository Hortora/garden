## Context

Building cognitive state management for AI agents (beliefs, trust, memory, personality-driven cognition) — assumed these capabilities needed to be built from scratch. An initial audit of neocortex found basic APIs (memory-api, mindmap-api) but missed the higher-level cognitive components.

## The behaviour

Neocortex already has a complete cognitive stack, fully built and undiscovered by application consumers:

| Component | Module | What it does |
|-----------|--------|-------------|
| `CognitiveProfile` | cognitive-index | Takes a `CognitiveProfileQuery`, resolves mindmap node, collects memories across 6 domains (Experience, Relationship, Reflection, Mood, Engagement, Affect), computes affect trajectory → returns `EntityKnowledge` |
| `PerspectivalResolver` + `PerspectivalMerge` | mindmap-intelligence | Per-principal overlay nodes on shared mindmap nodes. `merge(shared, overlay)` produces character-specific perspective — "HC sees the world differently than Penelope" |
| `CognitiveDerivationEngine` | cognitive-index | Derives `CognitiveDefaults` from Eidos-like `DescriptorView`: `PersonalityWeights` from Jungian function stack, `MoodBaseline` from disposition, `SocialCognitionDefaults` (trustFormationRate, conflictInterpretation), `CuriosityConfig`, `TemporalFocusConfig` |
| `ConversationBridge` | mindmap-intelligence | `process(text, tenantId, recentEntityNames, principalId)` → segments text, creates nodes with confidence + provenance, fires async LLM entity extraction via `MindMapExtractor`, detects contradictions |
| `ConsolidationScheduler` + 4 phases | mindmap-intelligence | AccessFrequencyPhase, MergeDetectionPhase, CommunitySummaryPhase, CuriosityRefreshPhase — automatic memory consolidation |
| `TemporalFocus` + `AttentionItem` | cognitive-index | Ranks temporal entries by proximity, recency, affect trajectory — "what should the character be thinking about" |
| `TypeRegistry` | mindmap-intelligence | Dynamic type registration — `SubgraphType` migrated from enum to strings. `registerType("belief", "concept", tenantId)` works now |

Additionally: `MindMapNode.principalId()` + `sharedWith()` provides per-character isolation with explicit sharing. PAD affect on every node. `ConfidenceOrigin` (STATED/INFERRED/SPECULATED). `TemporalMark` with validFrom/validUntil. `MindMapVocabulary` with per-type decay half-life.

## Why this is non-obvious

The neocortex repo is large (~45 modules). API-level audits (reading mindmap-api, memory-api) miss the higher-level cognitive components in mindmap-intelligence and cognitive-index. A first audit found "no cognitive classification, no on-demand consolidation, no personality→cognition derivation." A deep re-audit — reading actual implementations, not just interfaces — found all of these already existed. The components are built, tested, and wired via CDI. No application has consumed them yet.
