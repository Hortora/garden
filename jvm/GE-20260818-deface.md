### Symptom

MVEL3 compilation fails with:

```
io.casehub.engine.internal.engine.MvelExpressionEngineTest.Transaction
is defined in an inaccessible class or interface
```

### Context

Test POJOs (`TransactionCase`, `Transaction`) declared as `public static` inner classes of a package-private JUnit test class (`MvelExpressionEngineTest`). MVEL3 generates Java source in `org.mvel3` package — the outer test class is inaccessible from there.

### Root cause

Java access rules: a `public static` inner class is only accessible if the enclosing class is also accessible. Package-private enclosing class → inner classes are invisible to generated code in other packages.

### Fix

Move test POJOs to top-level public classes in their own files:

```java
// Bad: inner class of package-private test
class MvelExpressionEngineTest {
    public static class Transaction { ... }  // inaccessible to org.mvel3
}

// Good: top-level public class
public class TestTransaction { ... }  // accessible from any package
```

### Why this is non-obvious

The inner classes are `public static` — they look accessible. The enclosing class visibility constraint is enforced at compile time by MVEL3's in-memory Java compiler, not at the MVEL expression parsing stage.
