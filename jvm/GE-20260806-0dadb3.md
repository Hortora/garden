### Discovery
The `quarkus-mcp-server-http` artifact exposes two MCP transport endpoints simultaneously without any configuration:

- **Streamable HTTP**: `http://localhost:{port}/mcp` (MCP 2025-03-26 spec)
- **SSE**: `http://localhost:{port}/mcp/sse` (legacy MCP SSE transport)

Confirmed by Quarkus startup log:
```
MCP HTTP transport endpoints [streamable: http://localhost:8081/mcp, SSE: http://localhost:8081/mcp/sse]
```

### Why this matters
MCP clients vary in transport support — older clients use SSE, newer ones use streamable HTTP. Having both active means a single sidecar serves both without configuration.

### What's not documented
Whether the dual-transport exposure is configurable (can you disable one?), whether both share the same tool registry, and whether there are performance or connection-limit differences between the two transports.
