### Summary

`EventStreamBus<T>.subscribe(predicate, consumer)` delivers `LevelEvent<T>` to the consumer callback, not raw `T`. Method references typed to `T` fail with "incompatible types: `LevelEvent<T>` cannot be converted to `T`".

### Context

When wiring a `MarketConditionCloudEventPublisher` to the L3 bus (`EventStreamBus<RegimeAssessment>`), the natural wiring is `l3Bus.subscribe(e -> true, publisher::onRegimeAssessment)`. This fails at compile time because the subscriber receives `LevelEvent<RegimeAssessment>`, not `RegimeAssessment`.

### What was tried

Direct method reference: `l3Bus.subscribe(e -> true, publisher::onRegimeAssessment)` — compilation error.

### Root cause

`EventStreamBus` wraps every event in `LevelEvent<T>` which carries the payload, timestamp, level name, and metadata. The subscribe callback signature is `Consumer<LevelEvent<T>>`, not `Consumer<T>`.

### Fix

```java
l3Bus.subscribe(e -> true, le -> publisher.onRegimeAssessment(le.payload()));
```

### Why this is non-obvious

The bus is parameterised as `EventStreamBus<RegimeAssessment>`, suggesting the callback type is `RegimeAssessment`. The `LevelEvent` wrapper is an internal concern of the summarisation framework — the generic parameter `T` on the bus matches the payload type, not the delivered type.
