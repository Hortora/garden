## Context

Creating a CDI `@Decorator` that implements an interface with 3 abstract methods (`put`, `get`, `scan`). Only overrode `put()` — expected `@Delegate` to handle delegation for the remaining abstract methods automatically.

## Symptom

```
io.casehub.work.federation.FederationGuardStore is not abstract and does not override
abstract method scan(io.casehub.work.api.WorkItemQuery) in io.casehub.work.api.spi.WorkItemStore
```

Compile-time error, not a runtime error.

## Root Cause

`@Delegate` handles delegation at CDI **runtime** proxy level — the CDI container generates a proxy that wraps calls and routes unoverridden methods to the delegate. But the decorator class must satisfy the Java **interface contract at compile time**. Java requires all abstract methods to be implemented in a concrete class, regardless of CDI annotations.

The `@Delegate` annotation is a CDI instruction to the container, not a Java language feature. The compiler doesn't know about CDI and enforces standard Java rules.

## Fix

Explicitly implement all abstract interface methods with `delegate.method()` calls. Default methods on the interface do not need explicit implementation — only abstract ones.

```java
@Decorator
@Priority(Interceptor.Priority.APPLICATION)
public class FederationGuardStore implements WorkItemStore {

    @Delegate @Inject @Any
    WorkItemStore delegate;

    @Override
    public WorkItem put(WorkItem item) {
        // custom logic here
        return delegate.put(item);
    }

    // Must explicitly implement — abstract in interface
    @Override
    public Optional<WorkItem> get(UUID id) {
        return delegate.get(id);
    }

    // Must explicitly implement — abstract in interface
    @Override
    public List<WorkItem> scan(WorkItemQuery query) {
        return delegate.scan(query);
    }

    // Default methods (findByCallerRef, scanAll, etc.) are inherited — no override needed
}
```

## Why this is non-obvious

The `@Delegate` annotation and CDI documentation suggest that decorators only need to override methods they want to intercept. Some framework documentation (e.g. Weld) describes delegation as "automatic" — which it is, but only at runtime. The compile-time contract is pure Java, and Java doesn't know about `@Delegate`.
