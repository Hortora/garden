### The convention
casehub-ops case descriptor tests mock `ApplicationLifecycleService` and `NodeConvergenceTracker` using anonymous inner classes that override only the method under test. `WorkerScope` is provided via `IncidentResponseCaseDescriptorTest.TestWorkerScope` — a package-visible record implementing the interface.

### Known alternative
Mockito — the standard Java mocking framework. Not used because it is not in the test dependencies. The anonymous inner class approach is lighter and sufficient for the narrow mocking surface (1-2 methods per test).

### Example

```java
// Service mock — override only the method the worker calls
ApplicationLifecycleService mockService =
    new ApplicationLifecycleService() {
        @Override
        public Set<String> updateServiceImage(UUID appId, String serviceId,
                                               String newImage, String tenancyId) {
            return Set.of("cluster-1:gateway:deployment");
        }
    };

// WorkerScope mock — shared record from IncidentResponseCaseDescriptorTest
UUID caseId = UUID.randomUUID();
WorkerScope scope = new IncidentResponseCaseDescriptorTest.TestWorkerScope(caseId);

// NodeConvergenceTracker — real instance with noop signal handler
NodeConvergenceTracker tracker = new NodeConvergenceTracker(
    (caseId2, path, value) -> {},
    new ObjectMapper().registerModule(new JavaTimeModule()));
```

### Why this choice
Mockito adds a transitive dependency tree (ByteBuddy, Objenesis) that the project has chosen not to take. The case descriptor worker methods are static or package-visible with simple signatures — anonymous inner classes are adequate and keep the dependency footprint minimal.
