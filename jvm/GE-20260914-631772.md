## Jandex MethodInfo has no parameterAnnotation(int, DotName) — must iterate method.annotations() and filter by position

**ID:** GE-20260914-631772
**Stack:** Jandex 3.x
**Symptom:** Compilation error: `cannot find symbol: method parameterAnnotation(int, org.jboss.jandex.DotName)` in `org.jboss.jandex.MethodInfo`.
**Context:** When building an annotation processor that needs to read annotations on method parameters (e.g. `@PathParam` on SPI interface parameters), the natural API call would be `method.parameterAnnotation(index, annotationName)`. This method does not exist on `org.jboss.jandex.MethodInfo`.

### What was tried (didn't work)
- Called `method.parameterAnnotation(i, PATH_PARAM_ANN)` — does not compile; method doesn't exist
- Checked `MethodInfo` Javadoc for parameter annotation access — no direct method
- Checked `MethodParameterInfo` — exists but has no `annotation(DotName)` method either

### Root cause
Jandex stores all annotations (class-level, method-level, field-level, parameter-level) in a flat list on `MethodInfo.annotations()`. Parameter annotations are distinguished by their target kind (`AnnotationTarget.Kind.METHOD_PARAMETER`) and position (`target().asMethodParameter().position()`). This is a data-model choice — Jandex's index stores annotations by their declaring element, not by their logical target.

### Fix
Create a helper method that iterates `method.annotations()`, filters by target kind and position, and returns the matching `AnnotationInstance`:

```java
private static AnnotationInstance findParameterAnnotation(MethodInfo method, int paramIndex, DotName annotationName) {
    for (AnnotationInstance ann : method.annotations()) {
        if (ann.target().kind() == AnnotationTarget.Kind.METHOD_PARAMETER
                && ann.target().asMethodParameter().position() == paramIndex
                && ann.name().equals(annotationName)) {
            return ann;
        }
    }
    return null;
}
```

### Alternatives considered
- Using `method.parameterTypes().get(i)` to access parameter annotations — `Type` objects don't carry annotations in Jandex's model
- Using `javax.lang.model.element.ExecutableElement.getParameters()` instead of Jandex — works for standard APT but not when the annotation processor reads from pre-built Jandex indexes (the interfaces aren't in the current compilation round)

### Why this is non-obvious
Most annotation reflection APIs provide direct parameter annotation access: `java.lang.reflect.Parameter.getAnnotation()`, `javax.lang.model.element.VariableElement.getAnnotation()`. Jandex's flat-list model is a departure that the API shape doesn't hint at — there's no compile-time indication that `parameterAnnotation()` is missing until you try to call it.
