### Symptom

Replacing a dependency on `casehub-agency-agentic-yaml` (with exclusions for `casehub-agency`, `casehub-agency-core`, `casehub-platform-schema-generator`) with a dependency on `casehub-agency-agentic-yaml-deployment` causes Maven Enforcer `DependencyConvergence` failure:

```
jsonschema-generator:5.0.0 (via agentic-yaml-deployment → agentic-yaml → platform-schema-generator)
jsonschema-generator:4.38.0 (via platform-agent-claude → anthropic-java-core)
```

### Context

The original dependency had three exclusions to avoid pulling in heavy orchestration modules. When switching to the `-deployment` module (which transitively depends on the runtime module), those exclusions are lost because Maven exclusions are per-dependency-declaration, not inherited through transitive paths.

### Root cause

Maven exclusions are **not transitive**. If module A excludes X from its dependency on B, and module C depends on A, C does NOT inherit A's exclusion of X. The exclusions must be re-declared at each point in the dependency tree where the conflict surfaces.

### Fix

Re-apply the same exclusions on the new dependency:

```xml
<dependency>
    <groupId>io.casehub</groupId>
    <artifactId>casehub-agency-agentic-yaml-deployment</artifactId>
    <version>${project.version}</version>
    <exclusions>
        <exclusion>
            <groupId>io.casehub</groupId>
            <artifactId>casehub-agency</artifactId>
        </exclusion>
        <exclusion>
            <groupId>io.casehub</groupId>
            <artifactId>casehub-platform-schema-generator</artifactId>
        </exclusion>
    </exclusions>
</dependency>
```

### Why this is non-obvious

The refactor feels like a simple dependency swap — "depend on the deployment module instead of the runtime module." The exclusions on the old dependency are easy to overlook because they're boilerplate that was written once and forgotten. The error message points at `jsonschema-generator` versions, not at the missing exclusions, so the connection between "I changed a dependency" and "a transitive I never heard of now conflicts" requires tracing the full dependency tree.
