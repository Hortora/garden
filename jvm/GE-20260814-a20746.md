### Context
Need to project high-dimensional vectors (e.g. 1024-dim embeddings) to 2D coordinates for scatter plot visualization. External libraries (SMILE, Apache Commons Math) add heavy dependencies. Classical MDS can be implemented in ~80 lines of Java.

### Technique
Classical MDS works by:
1. Square the distance matrix
2. Double-center it: `B = -0.5 * (D² - rowMeans - colMeans + grandMean)`
3. Extract the top 2 eigenvectors via power iteration
4. Scale by sqrt(eigenvalue) to get coordinates

Key implementation detail: the initial vector for power iteration must NOT be uniform (`[1/√n, 1/√n, ...]`) — this aligns with the null space for symmetric inputs. Use an asymmetric initial vector:

```java
double[] v = new double[n];
double initNorm = 0;
for (int i = 0; i < n; i++) { v[i] = i + 1.0; initNorm += v[i] * v[i]; }
initNorm = Math.sqrt(initNorm);
for (int i = 0; i < n; i++) v[i] /= initNorm;
```

After extracting the first eigenvector, deflate the matrix (`B -= λ·v·vᵀ`) and repeat for the second dimension.

### Why this is non-obvious
Most developers reach for t-SNE or UMAP libraries for dimensionality reduction. Classical MDS is less well-known but has advantages: deterministic (same input = same output), no hyperparameters to tune, and trivially implementable in pure Java. The asymmetric initialization requirement is the non-obvious part — uniform initialization silently produces zero-coordinate outputs with no error.
