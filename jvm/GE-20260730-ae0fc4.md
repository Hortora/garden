## Symptom

`IllegalStateException: No ChatModelProvider found for: ANTHROPIC` thrown during `Worker` construction in a unit test, before any worker is invoked.

## Context

Building a `Worker` with an `AgentWorkerFunction` wrapping `Agent.builder().model(ModelType.ANTHROPIC).build()`. The worker will never fire in Bootstrap routing mode (rule-based wins by insertion order), but the `Agent` is built eagerly at registration time, not lazily at invocation time.

## Root cause

`AgentBuilder.build()` resolves the `ChatModel` via `ServiceLoader.load(ChatModelProvider.class)` immediately. If `langchain4j-anthropic` is not on the classpath, the ServiceLoader finds no provider and throws. This happens at worker construction — not when `Agent.execute()` is called.

## Fix

When the `ChatModel` runtime is not available, register the worker with `Worker.builder().noFunction().build()` instead. The worker exists for routing awareness but cannot execute. When the runtime dependency is added, switch to `Agent.builder().model(chatModel).build()` with an injected or resolved `ChatModel`.

```java
public static Worker create(ChatModel chatModel) {
    if (chatModel == null) {
        return Worker.builder()
                .name("llm-ioc-enrichment")
                .capabilityName("ioc-enrichment")
                .noFunction()
                .build();
    }
    var agent = Agent.builder()
            .systemPrompt(SYSTEM_PROMPT)
            .model(chatModel)
            .responseSchema(OutputContract.class)
            .build();
    return Worker.builder()
            .name("llm-ioc-enrichment")
            .capabilityName("ioc-enrichment")
            .function(new AgentWorkerFunction(agent))
            .build();
}
```

## Why this is non-obvious

The `Agent.builder()` API looks like a configuration builder — you'd expect it to defer model resolution until `execute()` is called. The eager resolution is hidden inside `build()`, three levels deep in a `ServiceLoader.load()` call. Nothing in the API signals that construction requires the runtime provider to be available.
