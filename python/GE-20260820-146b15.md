### The technique
When training a model on multi-source data where different sources have different feature availability patterns (e.g., Source A has both player and opponent features, Source B has only opponent), set the modality dropout rate during training to approximate the actual proportion of missing-modality samples in the combined dataset — not a fixed low value like 10-20%.

### Context
Strategy classifier trained on 3 data sources:
- SC2EGSet: ~40% of data, both modalities present
- SpawningTool: ~27% of data, opponent features only (player zeroed)
- MSC: ~33% of data, player features only (opponent zeroed)

Default 20% modality dropout meant the model saw 80% complete samples during training but only ~40% at test time. The model overfit to the "both present" regime.

### What developers would normally do
Use a standard small dropout rate (10-20%) for modality dropout as a regularization technique, without considering the actual data distribution. Most modality dropout papers suggest fixed rates.

### The fix
Match dropout rate to data distribution. With ~33% player-only and ~27% opponent-only in the real data, a dropout rate of 40% (20% player-dropped, 20% opponent-dropped) better approximates test-time conditions.

```python
# Before: fixed low rate
train_ds = ModalityDropoutDataset(train_samples, drop_prob=0.2)

# After: calibrated to actual missing rate
train_ds = ModalityDropoutDataset(train_samples, drop_prob=0.4)
```

Result: accuracy improved across all 3 matchups (+1.9%, +0.4%, +4.1%).

### Why this is non-obvious
Modality dropout is usually treated as a regularization hyperparameter (like standard dropout) and tuned by grid search. The connection between the dropout rate and the actual source distribution is rarely discussed in the literature. The improvement is subtle — each matchup gains modestly, but the compound effect across all matchups is significant.
