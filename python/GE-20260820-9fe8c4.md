### Symptom
Dual-encoder model with simple additive fusion `x = p * has_player + o * has_opponent` produces dramatically different per-class accuracy distributions depending on which modality is available. When both modalities present, accuracy shifts to favor one class at the expense of others.

### Context
Multi-source classifier where some data sources have only player features (119 dims), some only opponent features (120 dims), and some have both. Separate Conv encoders process each modality. Availability flags (0/1) gate each encoder's output before fusion.

### What was tried (didn't work)
Simple additive fusion: `x = p * has_player + o * has_opponent`. When both present, `x ≈ p + o` (magnitude ~2x). When one present, `x ≈ p` or `x ≈ o` (magnitude ~1x). The downstream layers receive inputs at inconsistent scales. MECH_PUSH accuracy jumped +29% while BIO_TIMING dropped -28%.

### Root cause
Additive fusion without normalization creates a scale discontinuity. The attention layer and classifier see a bimodal distribution of input magnitudes. The model can't learn weights that work for both scales simultaneously, so it optimizes for one regime at the expense of the other.

### Fix
Two viable approaches:

**Normalized averaging:**
```python
n_available = (has_player + has_opponent).clamp(min=1.0)
x = (p * has_player + o * has_opponent) / n_available
```

**Learned sigmoid gating (preferred):**
```python
self.gate = nn.Linear(2, 2)  # input: [has_player, has_opponent]
g = torch.sigmoid(self.gate(avail))
x = g[:, 0:1].unsqueeze(1) * p + g[:, 1:2].unsqueeze(1) * o
```
Learned gating lets the model discover that opponent features are more informative than player features for this classification task.

### Why this is non-obvious
The additive fusion looks correct — gating by availability seems like a clean design. The scale mismatch only manifests as per-class accuracy shifts, not as training failures or NaN losses. Without a per-source accuracy breakdown, the overall accuracy change (+1.4%) masks the dramatic per-class redistribution.
