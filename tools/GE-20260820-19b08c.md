### Symptom

When workspace repos are nested inside a parent directory that is itself
a git repo (e.g., `~/public/casehub/connectors/` where both `casehub/`
and `connectors/` have `.git`), a parent-first resolution algorithm
resolves ALL child repos to the parent. Multiple independent workspace
repos appear as one shared repo.

### Context

Common in multi-repo families where a parent directory was git-initialised
for convenience or migration reasons. Each child directory is its own
git repo with independent history, but naive `.git` detection walks
upward and finds the parent first.

### What was tried (didn't work)

```python
target = wksp.resolve()
parent = target.parent
if (parent / ".git").exists():
    return parent, "work"  # Wrong — returns parent for ALL children
if (target / ".git").exists():
    return target, f"work-{target.name}"
```

The parent check fires first because `parent / ".git"` exists. The
child check is never reached.

### Root cause

The resolution algorithm checks `parent/.git` before `target/.git`.
Since both exist, the parent always wins. This produces an N:1 mapping
(all children resolve to one parent) instead of the 1:1 mapping that
exists on disk.

### Fix

Use `git rev-parse --show-toplevel` which correctly resolves to the
nearest enclosing `.git` from the target path:

```python
rc, stdout, _ = run_cmd(["git", "-C", str(target), "rev-parse", "--show-toplevel"])
ws_root = Path(stdout.strip())  # Resolves to child, not parent
```

### Why this is non-obvious

The parent-first check looks reasonable — "find the repo root by walking
up." It works correctly when there is exactly one `.git` in the ancestry.
The failure mode is silent — no error, just the wrong repo resolved —
and only manifests when the parent directory happens to also be a git
repo.

### Alternatives considered

- Checking `target/.git` before `parent/.git` — fixes the immediate bug
  but still uses manual `.git` detection instead of git's own resolution
- Using `pathlib.parents` iteration — same problem, different syntax
