### Symptom

Entity dedup using Jaro-Winkler alone produces false merges — strings with similar structure but different semantic content score above threshold. Example: "Assert independence within intimate relationships" (JW=0.85) merged with "Assert Mexican and indigenous identity through visual representation" — completely different goals.

### Context

Goal dedup in a biographical knowledge graph with 138 goals. Naive JW ≥ 0.85 produced 12 merges including 2 false positives. Full pairwise LLM semantic comparison would require evaluating 9,453 pairs — expensive and slow.

### Fix

Two guards that must BOTH pass:

```python
def _word_set(name):
    stops = {'a', 'an', 'the', 'and', 'or', 'in', 'of', 'to', 'for', 'from',
             'with', 'as', 'by', 'on', 'at', 'into', 'through', 'during'}
    return {w for w in name.lower().split() if w not in stops and len(w) > 2}

def _jaccard(a, b):
    if not a or not b: return 0.0
    return len(a & b) / len(a | b)

jw = jaro_winkler(name_a, name_b)
jac = _jaccard(_word_set(name_a), _word_set(name_b))

is_match = jw >= 0.90 and jac >= 0.50 and same_type
```

**Results:**
- JW alone at 0.85: 12 merges, 2 false positives (83% precision)
- JW ≥ 0.90 + Jaccard ≥ 0.50: 2 merges, 0 false positives (100% precision)
- Near-miss candidates (JW ≥ 0.75 OR Jaccard ≥ 0.60): 341 pairs for LLM judgment
- Search space reduction: 9,453 → 341 (96% reduction)

The false merge "Assert independence..." had Jaccard = 0.11 — blocked by the 0.50 threshold.

### Why this is non-obvious

Jaro-Winkler is the standard string similarity metric for entity matching. The intuition is that high JW score = similar strings = likely duplicates. But JW is structural — it measures character-level edit distance, not semantic content. Two strings with the same grammatical structure ("Verb noun preposition noun") score high even when the content words are completely different. Jaccard on content words catches this because it compares what the strings are *about*, not how they're *spelled*.

### Caveats

- The 0.50 Jaccard threshold is calibrated for goal descriptions (typically 5-10 content words). Shorter strings may need a lower threshold.
- This is a pre-filter, not a replacement for semantic judgment. The 341 near-misses still need LLM evaluation. The technique's value is reducing the LLM workload by 96%.
