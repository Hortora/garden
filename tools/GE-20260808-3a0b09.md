### Symptom
Free-form tag systems accumulate synonyms ("auth" vs "authentication",
"config" vs "configuration") that fragment the taxonomy. String similarity
catches trivial cases but misses semantic synonyms ("DI" vs "injection").

### Context
Entries have both tags (metadata) and dense vector embeddings. No NLP
service or thesaurus available. Need to find tag pairs that cover the
same semantic space with different names.

### Root cause
Synonymous tags rarely co-occur on the same entry (a curator uses one or
the other, not both). So co-occurrence analysis sees them as unrelated.
String-distance approaches miss semantic equivalence.

### Fix
Compare the average embedding vectors of each tag's entry set. Tags whose
entry sets have high vector similarity (>0.8 cosine) but low co-occurrence
are synonym candidates.

Three pre-filters keep the O(T²) tag-pair comparison tractable:

1. **Domain overlap** — only compare tags whose entries share at least one
   domain. Tags in completely disjoint domains are unlikely synonyms.
2. **Co-occurrence exclusion** — skip pairs where >30% of entries carry
   both tags. High co-occurrence means coupled concepts, not synonyms.
3. **Per-domain centroid comparison** — compute average vectors within
   shared domains only, not globally. Avoids fetching all vectors.

```java
for (int i = 0; i < tags.size(); i++) {
    for (int j = i + 1; j < tags.size(); j++) {
        String tA = tags.get(i), tB = tags.get(j);

        // Pre-filter 1: must share at least one domain
        if (Collections.disjoint(tagDomains.get(tA), tagDomains.get(tB))) continue;

        // Pre-filter 2: high co-occurrence = coupled, not synonyms
        long coCount = tagIndex.get(tA).stream()
            .filter(e -> e.tags().contains(tB)).count();
        if (coCount > Math.min(tagIndex.get(tA).size(), tagIndex.get(tB).size()) * 0.3)
            continue;

        // Compare centroids per shared domain
        for (String domain : sharedDomains) {
            float[] centA = avgVector(tagIndex.get(tA), domainVectors);
            float[] centB = avgVector(tagIndex.get(tB), domainVectors);
            if (centA != null && centB != null) {
                totalSim += cosineSimilarity(centA, centB);
                domainCount++;
            }
        }

        if (domainCount > 0 && totalSim / domainCount > 0.8) {
            // Synonym candidate
        }
    }
}
```

### Why this is non-obvious
The natural approach to synonym detection is NLP — WordNet lookups, edit
distance, or language model embeddings of the tag strings themselves.
Using the embedding geometry of the *tagged entries* instead of the tag
*names* is indirect but more robust: it catches semantic synonyms that
no string comparison would find ("DI" and "injection") and works without
any external NLP dependency.
