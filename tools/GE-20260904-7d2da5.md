### Symptom
After upgrading from `kokoro-multi-lang-v1_0` to `kokoro-multi-lang-v1_1`, English voices (including the flagship `af_heart`) develop a noticeable accent and sound degraded compared to v1.0.

### Context
The Kokoro TTS model is distributed via sherpa-onnx releases. The version numbering (`v1_0` → `v1_1`) implies v1.1 is an improvement, but the models serve different language markets.

### Root cause
`kokoro-multi-lang-v1_1` is optimized for Chinese with only 3 English voices. `kokoro-multi-lang-v1_0` is the multi-language English-focused model with 53 voices across 8 languages. The version number is misleading — v1.1 is a Chinese specialization, not a universal upgrade.

### Fix
Use `kokoro-multi-lang-v1_0` for English TTS:

```java
Path modelDir = Provisioner.ensureKokoroModel("kokoro-multi-lang-v1_0");
```

### Why this is non-obvious
Version 1.1 > 1.0 universally implies "better." Without A/B testing the voice output, you'd assume v1.1 is the correct choice. The accent difference is subtle enough that it takes direct comparison to notice, and the model metadata doesn't document the language specialization.
