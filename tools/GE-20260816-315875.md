### What exists
`slot_manager.py` has a complete `add_repo()` function at line 698 that handles:
- Cloning the repo into the slot (`git clone --shared`)
- Creating the feature branch
- Setting up symlink exclusions and gitignored asset symlinks
- Maven config for isolated `.m2`
- ISX remote wiring (if applicable)
- Workspace resolution and setup (wksp/proj symlinks, CLAUDE.md replication)
- Updating `.slot` to include the new repo
- Workspace validation

### What's missing
The CLI `main()` function (line 1933) does not include an `add-repo` case in its subcommand dispatch. The `--help` output and error messages list available subcommands but `add-repo` is not among them.

### How to use it
Call the function directly via Python import:

```python
python3 -c '
import sys; sys.path.insert(0, "/path/to/skills/work-slot")
from slot_manager import add_repo; from pathlib import Path
add_repo(Path("/family/root"), slot_number, "repo-name", "branch-name")
'
```

### Why this is undocumented
The work-slot skill SKILL.md documents `add-repo` as a supported operation with a CLI invocation pattern, but the Python implementation never wired it into the CLI dispatcher. The skill docs describe the intended interface; the code implements the logic; neither connects to the other.
