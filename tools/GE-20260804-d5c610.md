## Symptom

Need to cluster vector embeddings by semantic similarity without adding external ML libraries (Apache Commons Math, Smile, Weka) to a lightweight Quarkus app.

## Context

Garden analytics dashboard needs coverage density analysis — clustering entries per domain to detect redundant coverage (one tight cluster) vs diverse coverage (scattered points). Dense vectors from Qdrant are 1024-dimensional floats.

## Fix

Pre-compute the full NxN cosine distance matrix once, then run DBSCAN using array lookups instead of recomputing similarities:

```java
static double[][] computeDistanceMatrix(List<VectorEntry> entries) {
    int n = entries.size();
    double[][] dist = new double[n][n];
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            double d = 1.0 - cosineSimilarity(entries.get(i).vector(), entries.get(j).vector());
            dist[i][j] = d;
            dist[j][i] = d;
        }
    }
    return dist;
}

static int[] dbscan(double[][] distances, double eps, int minPts) {
    int n = distances.length;
    int[] labels = new int[n];
    Arrays.fill(labels, -2); // unvisited
    int clusterId = -1;

    for (int i = 0; i < n; i++) {
        if (labels[i] != -2) continue;
        List<Integer> neighbors = rangeQuery(distances, i, eps);
        if (neighbors.size() < minPts) { labels[i] = -1; continue; } // noise
        clusterId++;
        labels[i] = clusterId;
        List<Integer> seed = new ArrayList<>(neighbors);
        seed.remove(Integer.valueOf(i));
        for (int si = 0; si < seed.size(); si++) {
            int q = seed.get(si);
            if (labels[q] == -1) labels[q] = clusterId;
            if (labels[q] != -2) continue;
            labels[q] = clusterId;
            List<Integer> qNeighbors = rangeQuery(distances, q, eps);
            if (qNeighbors.size() >= minPts)
                for (int nb : qNeighbors) if (!seed.contains(nb)) seed.add(nb);
        }
    }
    return labels;
}
```

Key parameters for cosine-distance vectors: `eps=0.3` (30% dissimilarity threshold), `minPts=2`.

## Why this is non-obvious

Most developers reach for k-means (which requires knowing k in advance) or pull in a clustering library. DBSCAN is a better fit when cluster count is unknown, and the implementation is ~50 lines when you pre-compute the distance matrix. The pre-computation step makes rangeQuery O(n) per point instead of recomputing N cosine similarities each time.
