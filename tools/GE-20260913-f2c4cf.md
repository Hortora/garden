## Summary

When assessing whether DTW similarity between two time series is statistically significant, random permutation of one series produces systematically too-low p-values (inflated type I error). Use circular shift surrogates instead.

## Context

DTW similarity alone can't distinguish meaningful temporal alignment from coincidental co-movement. A significance test compares observed similarity against a null distribution — "how often does random alignment produce similarity this high?"

## What developers reach for first

Random permutation — shuffle one series' bucket order N times, recompute DTW each time, p-value = fraction ≥ observed. Standard permutation testing intuition.

## Root cause

Real time series are autocorrelated — adjacent values are similar because the underlying process changes gradually. Random permutation destroys this autocorrelation structure, producing surrogate series with no temporal structure. The null distribution is artificially easy to beat: any series with temporal structure (which both real series have) will appear "significant" against random noise. The test answers "does this series have temporal structure?" (trivially yes) instead of "is the temporal *alignment* meaningful?"

## Fix — circular shift surrogates

```java
var rng = new Random(seed);
int n = candidate.length;
for (int s = 0; s < surrogates; s++) {
    int shift = 1 + rng.nextInt(n - 1);
    double[][] shifted = new double[n][];
    for (int i = 0; i < n; i++) {
        shifted[i] = candidate[(i + shift) % n];
    }
    // Recompute DTW with shifted series
}
```

Circular shifts preserve the series' autocorrelation and spectral properties while destroying the temporal alignment between the two series. The null hypothesis becomes "is the temporal alignment meaningful?" — which is the right question.

## Why this is non-obvious

Permutation testing is the standard go-to for non-parametric significance. The autocorrelation problem is well-known in statistics but not in software engineering circles. A developer implementing DTW significance for the first time will naturally reach for random permutation and get systematically wrong results — with no obvious error signal.
