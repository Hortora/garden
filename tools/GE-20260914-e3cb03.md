### Symptom

An LLM given cognitive state (mood, drives, beliefs, narrative memory) alongside a character briefing produces WORSE dialogue when told how to use the state than when given the state as unlabeled profile data. An LLM judge scored the directive-laden version lower on groundedness, character consistency, and depth.

### Context

A multi-agent conversation between two AI characters (Leonardo da Vinci and Nikola Tesla), each with a detailed character briefing and a cognitive architecture that evolves across turns. Seven subsystems (mood, drives, mental model, user model, narrative, strategy, goals) render their state as PromptSections injected into the LLM prompt each turn.

The question: should each section include behavioral instructions ("these motivations pull at you — the strongest drive should steer what you talk about") or just present labeled values ("Curiosity: 1.0", "Belief: values universal energy (confidence: 0.8)")?

### What was tried (didn't work)

**Prose directives** — each cognitive section prefixed with 2–3 sentences of behavioral instruction:

```
Your emotional state shapes how you speak — warmth shows in generosity
of thought, arousal in the pace and intensity of your words, dominance
in whether you assert or defer. Let these feelings color your response
naturally:
Current emotional state:
- Pleasure: 0.94 (positive)
- Arousal: 0.50 (energetic)
- Dominance: 0.74 (confident)
```

Result: LLM judge scored baseline (no cognition) higher — 9/9/9/9/9 vs cognition 8/9/8/8/9. The judge noted: "Conversation B increasingly substitutes elevation of tone for precision of thought; by the final turns both speakers converge into a shared mystical register that blurs their distinct voices."

### Root cause

Behavioral directives override character-specific constraints in the briefing. All directives push the same direction — seek connection, reference memories, steer toward goals — regardless of character personality. Leonardo (INFP, collaborative, "observation-before-theory") and Tesla (INTJ, independent, "precision-in-physics") both receive the same behavioral nudges, and both converge toward the same harmonious register. The character briefing's unique constraints get diluted by the universal directive framing.

### Fix

Remove all prose directives. Present cognitive state as labeled structured data only:

```
Current emotional state:
- Pleasure: 0.94 (positive)
- Arousal: 0.50 (energetic)
- Dominance: 0.74 (confident)

== Motivational State ==
- Curiosity: 1.0 — baseline
- Competence: 0.6 — no engagement data
- Affiliation: 1.0 — 1 of 1 relationships neglected

Theory of Mind (nikola):
What you believe about the user:
  - Believes this is the one question that truly matters (confidence: 0.8)
What you think they want:
  - Wants to finally tell someone who will truly grasp the experience (0.8)
```

Result: cognition won — 9/9/9/9/9 vs baseline 9/9/9/8/8. The judge noted: "Cognition pulls ahead on depth and memory utilisation: it opens additional dimensions — the phenomenological cost of perception, the keystone/arch taxonomy of visions, and the lens-vs-instrument reframe — that baseline does not reach. Cognition's later turns also weave earlier threads more densely."

### Why this fix

The obvious approach is to write better directives — more nuanced, per-character, balanced. But that creates a maintenance burden (N characters × M sections = N×M directive strings to tune) and still imposes the author's assumptions about how cognitive state should manifest in behaviour. The profile-data approach is universal — same format regardless of character, scenario, or domain. The LLM integrates profile data emergently through the character briefing's own constraints, producing different behaviour for different characters without explicit instruction.

### Why this is non-obvious

Intuition says more instruction = better results. The opposite is true here — less instruction allows the LLM's own reasoning (informed by the character briefing) to produce more authentic, differentiated behaviour. The cognitive state as DATA is a resource the LLM draws from; as INSTRUCTIONS it becomes a constraint that overrides character identity. This is the difference between giving an actor a character sheet ("your motivation is curiosity at 0.9") versus giving them stage directions ("when your curiosity is high, ask probing questions"). The character sheet lets the actor embody the character; the stage directions make every actor perform the same way.

### Alternatives considered

- **Better directives** — more nuanced per-character instructions. Creates N×M maintenance burden and still imposes author assumptions.
- **Directive templates with character-specific parameters** — e.g. "As an [INFP/INTJ], use your [collaborative/independent] nature to...". Better than universal directives but still prescriptive.
- **No cognitive state at all** — pure character briefing. Works well (baseline scores 9 on most dimensions) but loses the depth and memory benefits that accumulated cognitive state provides.
