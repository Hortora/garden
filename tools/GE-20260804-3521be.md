## Symptom

`tmux display-message #{pane_current_command}` returns "2.1.221" instead of "claude" or a shell name

## Context

When checking if a tmux pane is running a shell (for agent launch verification), the foreground command check fails because Claude Code changes its process title to the version string.

## Root Cause

Claude Code (Node.js) sets `process.title` to the version number. tmux reads the process name from the OS which reflects this title change.

## Fix

Match version-string patterns (`\d+\.\d+\.\d+`) in addition to "claude" in the process name. Also add retry logic for empty `pane_current_command` (shell not yet initialized after tmux session creation).

## Why Non-Obvious

The version string looks nothing like a process name. Without knowing Claude Code sets `process.title`, the error "Terminal foreground is '2.1.221', not a shell" is baffling.
