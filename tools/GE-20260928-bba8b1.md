# Paired state probes with control — isolating LLM behavioral emergence from random variation

### Symptom

You need to prove that a cognitive system produces behaviorally different LLM responses when cognitive state changes — not just that observation sections exist (structural emergence), but that the LLM actually adapts its behavior (behavioral emergence). Single-state probes ("does cognitive state X influence behavior?") don't distinguish temporal adaptation from static influence.

### Context

LLM outputs are non-deterministic. Two calls with identical prompts produce different responses. Any eval that compares before/after LLM responses must separate cognitive-system-driven differences from random variation.

### Fix

**Paired state probes with no-cognition control:**

For each event scenario:
1. **Cognitive BEFORE:** Render observation sections with pre-event cognitive state. Call LLM with character voice card + observation + situation prompt. Record response.
2. **Cognitive AFTER:** Same character, same situation, but post-event cognitive state (modified drives, revised beliefs, shifted mood). Call LLM. Record response.
3. **Control probe 1:** Same character, same situation, NO observation sections. Call LLM. Record.
4. **Control probe 2:** Identical to control probe 1. Call LLM. Record.
5. **LLM judge:** Score the cognitive delta (BEFORE vs AFTER) and control delta (probe 1 vs probe 2) on a 0-5 scale for behavioral adaptation.
6. **Dual assertion:** `cognitive_delta >= threshold` AND `cognitive_delta > control_delta`.

The control pair establishes the random-variation baseline. If the cognitive pair's delta significantly exceeds the control's, the difference is from cognitive state, not LLM randomness.

### Why this is non-obvious

Most LLM evals test single outputs against rubrics. The naive approach — "run with cognitive state, check if behavior matches" — doesn't prove emergence because it doesn't isolate the cognitive system's contribution from the LLM's baseline behavior. A developer would typically reach for A/B testing (with vs without cognition) but miss that LLM non-determinism requires a control pair to establish the variation baseline.

### Alternatives considered

- Multi-tick simulation with organic state evolution — more realistic but requires complex store setup and doesn't strengthen the inference. The tick pipeline's correctness is better tested via unit tests.
- Embedding distance between responses — cheaper (no judge LLM) but measures only difference, not adaptive relevance. Random variation also produces distance.
- Human evaluation — most accurate but not automatable for CI.
