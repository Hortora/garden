### What
A Bash PreToolUse hook intercepts `git commit` commands and blocks them when orchestrator-managed steps haven't completed. Two gates:

1. **HANDOFF.md commit** — blocked unless `.close-progress` shows wrap orchestrator completed (wrap_sweep_config=done, handoff_write=done)
2. **Branch-closed stamp** — blocked unless `.close-progress` shows close orchestrator review completed (forcing_function=done)

### The technique
```bash
# PreToolUse hook registered in ~/.claude/settings.json
CMD=$(cat | python3 -c "import json,sys; print(json.load(sys.stdin).get('tool_input',{}).get('command',''))")

# Gate 1: HANDOFF.md commit without orchestrator
if echo "$CMD" | grep -qiE 'HANDOFF|handoff'; then
  PROGRESS="$TARGET_DIR/.close-progress"
  if [ -f "$PROGRESS" ]; then
    if ! grep -q "handoff_write=done" "$PROGRESS"; then
      echo "BLOCK: Wrap orchestrator not complete." >&2
      exit 2
    fi
  fi
fi

# Gate 2: branch stamp without review
if echo "$CMD" | grep -qE -- '-m\s+"chore: branch closed'; then
  if [ -f "$PROGRESS" ] && ! grep -q "forcing_function=done" "$PROGRESS"; then
    echo "BLOCK: Close orchestrator review not complete." >&2
    exit 2
  fi
fi
```

### Why this is non-obvious
The standard approach for controlling LLM behavior is SKILL.md instructions — "do X before Y", "don't skip Z." But the LLM is the outer loop and can choose to ignore any instruction. Hooks are the one enforcement mechanism the LLM cannot bypass: they fire on tool calls, not on skill instructions. The hook operates at a layer below the LLM's decision-making — it intercepts the git command before it executes, regardless of what the LLM intended.

The key architectural insight: in Claude Code, the LLM calls tools (Bash, Edit, Write). Hooks intercept tool calls. This is the only point where Python-level enforcement can prevent LLM behavior without the LLM's cooperation.

### Alternatives considered
- Stronger SKILL.md warnings — failed. LLMs treat instructions as suggestions.
- Git pre-commit hooks (in .git/hooks/) — would work but requires per-repo installation. Claude Code PreToolUse hooks are global and apply to all repos.
- Making the orchestrator the only way to commit — too restrictive. Normal development commits shouldn't be blocked.
