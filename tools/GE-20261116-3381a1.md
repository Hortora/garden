# Modular residue fingerprinting — identifying sliding window sizes and algorithm type from quantised output

## Context

You have a black-box rate-reporting system. You want to know whether it uses a sliding window or an EMA, and if a window — what length. Standard approach is to fit curves or sweep alphas. The modular residue technique is faster and more conclusive.

## Technique

Collect a large sample of output values (rate reports). Compute `value % expected_quantum` for each sample, where `expected_quantum = cargo_per_event × loops_per_minute / window_length`.

If the output is from a sliding window counting discrete events:
- All values satisfy `value % quantum == quantum - 1` (the -1 is from integer truncation)
- Or equivalently: `(value + 1) % quantum == 0`

The quantum size identifies the window length. Scan candidate window lengths until you find one where nearly all residues are identical.

## Example

SC2 `mineralsCollectionRate` values: scan for modular pattern.

```
5 minerals/delivery × 1344 loops/min / 240 loops = 28 minerals/min per delivery
```

Check: `mineralsCollectionRate % 28` across 118 replays → consistently 27.

Conclusion: SC2 counts deliveries in a 240-loop sliding window, integer-truncated. `rate = deliveries × 28 - 1`.

Confirmed: across thousands of rate events, only one value breaks the pattern (the ramp-up interval before the window fills).

## Why this is non-obvious

Alpha-sweeping is the standard approach for identifying EMA parameters. But it cannot distinguish EMA from a sliding window — both can be fitted with similar error. Modular residue analysis identifies the algorithm type and window length from a single observation, not a fitting procedure. A skilled developer would reach for regression; this gives a closed-form answer.

## Code

```python
import pandas as pd

rates = [...]  # collected rate values
for window_loops in [160, 200, 240, 320, 480]:
    cargo = 5  # e.g. mineral cargo per delivery
    loops_per_min = 1344
    quantum = cargo * loops_per_min // window_loops
    residues = [r % quantum for r in rates if r > 0]
    dominant = max(set(residues), key=residues.count)
    pct = residues.count(dominant) / len(residues)
    print(f"window={window_loops}: quantum={quantum}, dominant_residue={dominant}, match={pct:.1%}")
```

Window length with 99%+ match and residue = quantum-1 is the answer.
