### Symptom
`ide_open_project` fails with "multiple projects open, specify project_path" even though the target directory exists and is a valid project.

### Context
IntelliJ MCP plugin has multiple projects open. Calling `ide_open_project(path: "/new/project")` without `project_path` fails because the plugin needs to know which existing project to use as the JSON-RPC routing context.

### Root cause
The MCP plugin's JSON-RPC router requires a `project_path` parameter to identify the context project when multiple projects are managed. `ide_open_project` opens a NEW project but still needs an EXISTING project as the routing context for the RPC call.

### Fix
Pass any already-open project's path as `project_path`:
```typescript
ide_open_project({
  path: "/path/to/new/project",
  project_path: "/path/to/already/open/project"
})
```

### Why this is non-obvious
`project_path` sounds like it should be the path of the project you're opening. It's actually the routing context for the RPC call — a completely different purpose. The error message says "specify project_path" without clarifying this distinction.
