## Context

Cognitive agents in a tick-based simulation generate high-frequency state changes — every tick produces trust events, observations, action outcomes, and dialogue. The instinct is to write all cognitive state to a persistent knowledge graph immediately, maintaining a single always-current source of truth. But graph writes are expensive (node lookup, edge update, consistency checks, potential contradiction resolution), and at 5 agents × 300 ticks = 1,500+ write operations per scenario, this dominates tick latency.

## Technique

Three-tier memory model — each tier has different storage, lifecycle, and write frequency:

| Tier | What | Storage | Write frequency |
|------|------|---------|----------------|
| **Tier 1 — Working memory** | Current observation, last action, current thinking | In-process object | Every tick (rebuilt, not persisted) |
| **Tier 2 — Episodic buffer** | Recent events, trust events, experience | In-process list/map | Every tick (append-only) |
| **Tier 3 — Knowledge graph** | Beliefs, relationships, judgments, consolidated knowledge | Neocortex mindmap | **Consolidation only** (never during tick loop) |

The key rule: **Tier 3 is write-on-consolidation-only.** Trust events, belief triggers, and experiences are buffered in Tier 2 during gameplay. A "sleep" consolidation phase graduates worthy events from Tier 2 → Tier 3 using importance scoring (surprise, arousal, confidence).

Observation rendering queries BOTH tiers:
- "What's happening now" → Tier 1
- "What happened recently" → Tier 2
- "What I know/believe/feel" → Tier 3

## Why this is non-obvious

The instinct to write everything to a single persistent store is strong — it feels like the "correct" architecture. The three-tier model looks like premature optimization. But it mirrors how human cognition actually works (working memory → hippocampal buffer → neocortical consolidation during sleep), and it's validated by 40 years of cognitive architecture research:

- **Soar** has functionally separate modules but structurally unified working memory
- **ACT-R** has separate buffers feeding a shared production system
- Both are functionally modular, structurally unified at the reasoning layer — exactly the three-tier model

The consolidation mechanic also creates a game design opportunity: "night falls on the mansion" isn't just a plot device, it's when characters genuinely process and integrate what they've learned.
