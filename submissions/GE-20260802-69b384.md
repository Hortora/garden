## IntelliJ MCP ide_create_file in git worktrees — project_path targets the main repo, not the worktree

**ID:** GE-20260802-69b384
**Stack:** IntelliJ MCP plugin, git worktrees

### Symptom

Files created via `ide_create_file` with `project_path` pointing to the main repo appear in the main repo's working tree, not in the git worktree. If the `file` parameter includes a directory prefix matching the project subdir, the path doubles (e.g. `sidecar/sidecar/src/...`).

### Root Cause

IntelliJ MCP's `project_path` resolves to the IntelliJ project (where `.idea/` lives). Git worktrees share `.git` but have separate working trees. `ide_create_file` writes relative to the project root — the main repo, not the worktree.

### Fix

Open the worktree as a project first: `ide_open_project(path=<worktree-path>)` — `.idea` is NOT required. Then use `project_path=<worktree-path>` on all subsequent calls. Or use the `Write` tool directly for worktree files.

### Why This Is Non-Obvious

The plugin auto-opens projects when `project_path` is passed. For worktrees without `.idea`, it may route to the nearest known project. File creation succeeds silently — no error indicates the file landed in the wrong working tree.
