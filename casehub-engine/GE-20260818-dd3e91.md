### Symptom
`DecompositionStrategy.decompose()` attempts to return `DagPlan.fromNodes(List.of())` to signal "no plan found" — throws `IllegalArgumentException: nodes must not be empty`.

### Context
Implementing `GoapDecompositionStrategy` — multiple early-return paths (no actions, goal satisfied, planner returns empty) need to signal "no plan" to `DefaultGoalDecomposer`.

### Root cause
`DagPlan.fromNodes()` validates that the node list is non-empty and rejects empty lists. There is no `DagPlan.empty()` factory or null-safe return path in the `DecompositionStrategy` SPI.

### Fix
Throw an exception (e.g. `AgentException`) instead of returning an empty plan. `DefaultGoalDecomposer` already catches exceptions from `strategy.decompose()` for graceful degradation — the case continues without a plan via choreography.

```java
if (planned.isEmpty())
  throw new AgentException("GOAP decomposition produced no plan");
```

### Why this is non-obvious
The natural pattern is to return an empty collection to signal "nothing found." `DagPlan.fromNodes()` looks like the right factory but rejects the empty case. The fix (throwing) is correct because the caller's catch block is the designed graceful-degradation path.
